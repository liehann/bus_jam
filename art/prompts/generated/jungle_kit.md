# Jungle Café kit: one piece per Gemini chat

Attach `art/raw/jungle/mock.jpeg` (the Jungle Café level mock, image 1) to every prompt below, one new chat per piece,
and save each result as `art/raw/jungle/<piece>.<ext>` (the name after "Save as"). Then run
`python3 art/tools/theme_kit.py jungle`. What each piece is for: docs/ART-PIPELINE.md, "Level themes".

## backdrop

Image 1 is a mock of my mobile game. Using exactly its art style (flat 2D illustration, soft cel shading, thick dark brown outlines, lush tropical green palette with warm accents, soft dappled green daylight), paint the empty background scene of image 1 for a tall portrait phone screen, 9:20 aspect ratio: the same scene as image 1, a cozy jungle treehouse café for cute animals, seen from directly above, with every game piece removed. No conveyor belts, no loop or anything inside it, no plates, no kitchen, no counter, no benches, no animals, no board, no mat, no cards, no buttons, no text. The whole middle of the image is one calm, even, plain pale moss-green jungle floor with soft dappled light, nothing on it, because the game draws its pieces there. All decoration sits in a thin border along the edges only: big tropical leaves and hanging vines along the top and side edges, a few bright jungle flowers in the corners, a small parrot perched near a top corner, ferns in the bottom corners. Flat top-down view, no perspective.

Save as `backdrop`
