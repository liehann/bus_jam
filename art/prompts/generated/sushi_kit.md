# Sushi Bar kit: one piece per Gemini chat

Attach `art/raw/sushi/mock.jpeg` (the Sushi Bar level mock, image 1) to every prompt below, one new chat per piece,
and save each result as `art/raw/sushi/<piece>.<ext>` (the name after "Save as"). Then run
`python3 art/tools/theme_kit.py sushi`. What each piece is for: docs/ART-PIPELINE.md, "Level themes".

Flat top-down view, no perspective.
