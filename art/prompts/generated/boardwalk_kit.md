# Beach Boardwalk kit: one piece per Gemini chat

Attach `art/raw/boardwalk/mock.jpeg` (the Beach Boardwalk level mock, image 1) to every prompt below, one new chat per piece,
and save each result as `art/raw/boardwalk/<piece>.<ext>` (the name after "Save as"). Then run
`python3 art/tools/theme_kit.py boardwalk`. What each piece is for: docs/ART-PIPELINE.md, "Level themes".

Using exactly its art style (flat 2D illustration, soft cel shading, thick dark brown outlines, bright seaside pastel palette, bright soft seaside sunlight), paint the empty background scene of image 1 for a tall portrait phone screen, 9:20 aspect ratio: the same scene as image 1, a sunny seaside boardwalk snack bar for cute animals, seen from directly above, with every game piece removed. Flat top-down view, no perspective.
