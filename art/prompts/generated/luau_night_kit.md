# Luau Night kit: one piece per Gemini chat

Attach `art/raw/luau_night/mock.jpeg` (the Luau Night level mock, image 1) to every prompt below, one new chat per piece,
and save each result as `art/raw/luau_night/<piece>.<ext>` (the name after "Save as"). Then run
`python3 art/tools/theme_kit.py luau_night`. What each piece is for: docs/ART-PIPELINE.md, "Level themes".
