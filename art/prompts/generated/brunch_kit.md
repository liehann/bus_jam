# Sunny Brunch kit: one piece per Gemini chat

Attach `art/raw/brunch/mock.jpeg` (the Sunny Brunch level mock, image 1) to every prompt below, one new chat per piece,
and save each result as `art/raw/brunch/<piece>.<ext>` (the name after "Save as"). Then run
`python3 art/tools/theme_kit.py brunch`. What each piece is for: docs/ART-PIPELINE.md, "Level themes".
