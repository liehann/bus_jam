# Tea Party kit: one piece per Gemini chat

Attach `art/raw/tea_party/mock.jpeg` (the Tea Party level mock, image 1) to every prompt below, one new chat per piece,
and save each result as `art/raw/tea_party/<piece>.<ext>` (the name after "Save as"). Then run
`python3 art/tools/theme_kit.py tea_party`. What each piece is for: docs/ART-PIPELINE.md, "Level themes".
